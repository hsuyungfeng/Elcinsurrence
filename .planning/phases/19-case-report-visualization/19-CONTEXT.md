# Phase 19: Case Report 視覺化審查報告升級 (借鑑 answer-me-with-html 理念)

## 目標
借鑑 `answer-me-with-html` 的極簡高資訊密度、可收折卡片與圖文並排設計理念，升級第 2、3 階統一審查報告（`unified_review_report.py`）及預審卡片（`preview-html`）：
1. **Case Report 階層折疊卡片排版**：
   - 頂部彙整「案件精要 Summary 卡片」與「狀態/佐證 KPI 徽章」。
   - 核心區塊：**臨床 SOAP 病歷** 與 **佐證庫影像（縮圖+LightBox放大）** 並排/並列對照，方便審查醫師核對傷口/手術實況。
   - 折疊區塊：將冗長的「給付規定全文」與「健保跨院雲端病歷」改為原生 `<details>` 收合，按壓展開，避免滾動疲勞。
2. **多源檔案串流與直接預覽**：
   - 影像直接輸出縮圖與點擊放大。
   - 檢驗報告與錄音檔提供內嵌播放或直連。
3. **自包含無外部相依**：
   - 純原生 HTML5 + 內嵌 CSS，不依賴外部 CDN，極速離線開啟，符合 PHI 安全轉義。
