# Plan 19-01: 重構 unified_review_report 視覺排版

## 目標
在 `src/elc_audit_engine/unified_review_report.py` 中重構 HTML 渲染邏輯，實作 Case Report 視覺化卡片排版。

## 任務細項
1. **版面 CSS 樣式升級**：
   - 支援雙欄對照網格（`grid` / `flex`）：左側精簡 SOAP、右側影像畫廊縮圖。
   - 影像縮圖樣式與點擊 LightBox 燈箱預覽 JavaScript（原生純腳本，免外部函式庫）。
   - 折疊區塊 `<details class="collapse-box">` 樣式美化（給付規定全文、雲端病歷）。
2. **區塊渲染器更新**：
   - 更新 `_section_soap` 與 `_section_vault`：支援佐證庫影像之內嵌 Base64/API 縮圖展示。
   - 更新 `_section_rule` 與 `_section_cloud`：改以折疊收合呈現，預設摺疊。
3. **單元測試驗證**：
   - 更新 `tests/test_unified_review_report.py`，驗證新版 HTML 結構、折疊標籤及跳過空區塊等行為。
