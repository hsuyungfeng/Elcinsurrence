# Plan 18-03: 重新設計自動化抽樣事前預審閉環與工作台

## 目標
針對抽樣案件（如 62022C 等高價處置）重新設計以全自動化為目標的事前預審流程，消除「病歷缺席／判定服務異常」，自動串接多源佐證與完成判定。

## 任務細項
1. **工作台自動化流程閉環**：
   - 點選案件（如 62022C / `L221543164-2307`）時：
     1. 自動帶入精簡版臨床 SOAP 病歷。
     2. 自動掛載對應 Evidence Vault 佐證庫檔案。
     3. 自動解析檢驗數據（Lab Results）與雲端病歷（健保跨院紀錄）。
     4. 自動觸發比對器進行「醫令支持度預先審核」，產生支持度評估（充分 ✅ / 薄弱 ⚠️ / 裸奔 ❌）。
2. **防禦性容錯與全自動補強**：
   - 解決本地病歷目錄缺席時的降級防護，提供合理的上下文替代，避免拋出服務異常。
   - 支援「一鍵套用 LLM 建議 SOAP」並自動將審核結果更新至案件庫。
   - 支援預審完成後一鍵生成「視覺化預審卡片 (HTML)」與「健保局抽審 XML」。
