<objective>
落實使用者四項核心需求：
1. 當月病例 ZIP 上傳後直接顯示範例病歷（無需每次等待重跑）。
2. 依照處置/手術醫令（如 64140C）生成紀錄要點 SOAP 存入 DB 作為通用範本（藥物不需）。
3. 預生成 >350 點醫令範本供醫師修改，並建立 LLM 生成品質審核機制（防幻覺、防佔位符）。
4. 建立申報檔案完整性檢核與醫師決策輔助準則。
協同工作流：由 Claude 擔任 Executor 實施程式碼，Hermes 執行測試，最後由 Antigravity (agy) 審核與修復。
</objective>

<tasks>
1. Task 1: 在 `soap_advice.py` 中建立 `validate_soap_quality(soap_dict)` 品質檢驗器（檢查 S/O/A/P 是否皆非空、長度符合、無 placeholder 如 "not documented"、"pending"、"missing" 等，並給出 quality_score 與 pass/fail）。
2. Task 2: 在資料庫建立通用手術處置範本快取表/Artifact 儲存（儲存 key: `order_code` + `primary_diagnosis`），當遇到相同醫令與診斷時直接讀取 DB，不必每次重新請求 LLM。
3. Task 3: 更新 `monthly_report_html.py` 與 `index.html`，讓上傳 TOTFA.zip 後的報告中，點數 >350 的醫令直接內嵌可展開/收合的範例病歷（含「📋 複製」、「✏️ 修改」與「💾 儲存」按鈕）。
4. Task 4: 編寫自動化測試 `tests/test_monthly_pregen_soap.py`，並透過 herdr 調度 Claude 實作與 Hermes 測試。
</tasks>
