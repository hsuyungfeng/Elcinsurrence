<objective>
修復 BLOCKER-2「金額/數量欄位鏈在兩層轉換中斷裂」：`deduct_amount`（DeductionRecord.non_reimbursed_amount）與 `order_seq`（欄 10）在 `_to_appeal_case`（server.py:382-410）與 `build_submission_from_case`（case_to_submission.py:57-123）兩層轉換中被靜默丟棄，導致紙本申復清單 PDF 的「金額」欄在所有真實案件（CSV 匯入與 API 生成兩條路徑）恆為空白＋「警告：金額」。
