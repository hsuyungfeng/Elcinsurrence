    Create `src/elc_audit_engine/rule_repository/embeddings/chroma_store.py` with `def flatten_tree_nodes(tree: dict, doc_label: str) -> list[dict]` — recursively walks a single document's tree (as produced by Plan 03) and returns a flat list of `{"id": f"{doc_label}::{node_path}", "text": node["full_text"], "metadata": {"doc": doc_label, "path": node["path"], "level": node["level"]}}` for every node with `len(node["full_text"].strip()) > 0`. Add `def build_chroma_collection(docx_trees_path: str, persist_dir: str, collection_name: str = "rule_articles") -> dict` (returns a summary dict `{"status": "ok"|"skipped", "chunks_ingested": int, "reason": str | None}`). Logic: (1) load `docx_trees_path` JSON; (2) flatten all documents' nodes via `flatten_tree_nodes`; (3) try `chromadb.PersistentClient(path=persist_dir)` and `client.get_or_create_collection(collection_name)`; (4) batch-add via `collection.add(ids=[...], documents=[...], metadatas=[...])` in chunks of 500 (ChromaDB has a max batch size, and 500 is safely under typical default limits for this corpus size); (5) wrap steps 3-4 in a broad `try/except Exception as e` — if ANY exception occurs (e.g., no internet for the first-use ONNX model download, per RESEARCH.md Assumption A2), catch it, log via `warnings.warn(f"ChromaDB ingestion skipped (non-blocking, D-09): {e}")`, and return `{"status": "skipped", "chunks_ingested": 0, "reason": str(e)}` — this must NEVER raise up to a caller, since D-09 is explicitly non-blocking and must not fail the phase's core acceptance criteria.

    Create `src/elc_audit_engine/rule_repository/scripts/build_chroma_index.py` as a standalone script (`if __name__ == "__main__":`) calling `build_chroma_collection(os.path.join(config.settings.DB_DIR, "docx_trees.json"), config.settings.RAG_DIR)` and printing the result summary. Run this script once — if it succeeds, `data/rag/` will contain a populated ChromaDB collection; if it fails (e.g., no internet), the printed `"skipped"` status with `reason` is acceptable and expected per D-09.

    Create `tests/test_chroma_store.py` with tests for `flatten_tree_nodes` (pure function, no ChromaDB dependency, always runs) and a `build_chroma_collection` test that is marked `@pytest.mark.skipif` guarded so it does not fail CI/offline runs if ChromaDB's embedding model isn't cached, but DOES verify the non-blocking contract when it does run.
