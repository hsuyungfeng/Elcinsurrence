## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Silent broad except in route handlers | Using `except Exception: pass` hides infrastructure errors and violates project boundary safety test | blocking | Must log exceptions (`current_app.logger.warning(...)`) or catch explicit domain exceptions |
| Hardcoded assumption of case persistence | Calling `store.get(case_id)` on unpersisted demo cases caused HTTP 500 error | blocking | Always wrap `store.get(case_id)` in try/except `CaseNotFoundError` and provide default fallback |
| OAuth App Token Workflow Scope Failure | Pushing via HTTPS fails when `.github/workflows` changes if OAuth token lacks workflow scope | advisory | Use authenticated SSH git remote (`git@github.com:hsuyungfeng/Elcinsurrence.git`) |
