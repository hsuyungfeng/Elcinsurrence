# Plan 28-02: 符合健保 11 碼標準檔名、四大屬性分類與 500MB ZIP 動態分包之電子病歷批次打包引擎

## 任務目標
依據「全民健保電子病歷抽審與申覆『批次打包與檔名自動化重命名』系統規格需求說明書 (`emr-batch-packaging-naming-spec.md`)」建置合規之電子病歷批次打包引擎：
1. **11 碼標準檔名自動重命名**：組合成 `[第1階 2碼] + [第2階 1碼 A/B/C/D] + [案件分類 2碼] + [流水號 6碼]` 及 `-1`, `-2` 擴充檔名。
2. **四大資料屬性分類 (A/B/C/D)**：自動分流病歷本文(A)、影像(B)、檢驗(C)、同意書(D)。
3. **A 類病歷本文結構化與 PDF 樹狀書籤**：將已比對之門診 SOAP 與處方箋輸出為含樹狀書籤（Bookmarks）之標準 PDF。
4. **500MB ZIP 動態分包與標準命名**：封包命名為 `{醫事機構代碼}_{民國日期}_{序號}.zip`，超過 450MB 自動分包裁切。
5. **源頭端品質驗證 (Validation-at-Source)**：防呆攔截中文檔名、非標準副檔名及缺少 DICOMDIR 之 DICOM 包。

---

## 預定修改與新建檔案

1. **新建模組 `src/elc_audit_engine/packagers/emr_batch_packager.py`**：
   - `EmrClassifier`：四階層資料屬性自動歸類器。
   - `Emr11CodeNaming`：健保 11 碼標準檔名編碼與擴充命名引擎。
   - `StructuredSoapPdfBuilder`：結構化 SOAP 轉製 PDF 引擎，插入樹狀書籤（病歷首頁、處方箋、SOAP 紀錄單）與電子簽章區。
   - `SourceQualityValidator`：源頭端品質合規驗證器。
   - `BatchZipPackager`：500MB 批次打包引擎，支援動態裁切與 `MANIFEST.txt`、`SHA256_CHECKSUM.txt` 封裝。

2. **擴充 API 路由與前端下載接點**：
   - 於 `src/elc_audit_engine/api/routes/packaging.py` 新增：
     - `POST /api/emr/batch-package`：執行當月抽審或申覆之 EMR 11 碼標準批次打包。
     - `GET /api/emr/packages/<batch_id>`：取得打包封包清單與容量報告。

3. **新增測試套件 `tests/test_emr_batch_packaging.py`**：
   - 驗證 11 碼檔名公式、半形字元校驗與多檔 `-1`, `-2` 切割規則。
   - 驗證動態容量累計：超過 450MB 自動裁切為 `_001.zip`、`_002.zip`。
   - 驗證 A 類 PDF 書籤結構與源頭品質預檢（阻斷中文檔名與缺少 DICOMDIR）。
