# Plan 24-01: SoapVoice 與 Elcinsurrence 跨倉資料管線與 EvidenceVault 自動歸檔

## 任務目標
1. **建立 Elcinsurrence 跨倉接收端點 (`/api/his/soapvoice-ingest`)**：
   - 在 [`src/elc_audit_engine/api/routes/his_integration.py`](file:///home/hsu/Desktop/Elcinsurrence/src/elc_audit_engine/api/routes/his_integration.py) 或獨立路由新增 `POST /api/his/soapvoice-ingest`。
   - 接收來自 [`SoapVoice`](file:///home/hsu/Desktop/Elcinsurrence/SoapVoice) 的 [`LANProcessResponse`](file:///home/hsu/Desktop/Elcinsurrence/SoapVoice/src/api/lan_process_api.py)，包含 `session_id`、`patient_name`、`id_card`、`visit_date`、`soap` (S/O/A/P)、`icd10_code`、`audio_bytes` (Opus) 與 `screenshot_bytes`。
2. **自動歸檔至多模態 EvidenceVault**：
   - 根據 `id_card` 與就醫年月（如 `2307`）計算合法 `vault_key`（正則符合 `^[A-Z][0-9]{9}-\d{4}$`）。
   - 透過 [`evidence_vault.py`](file:///home/hsu/Desktop/Elcinsurrence/src/elc_audit_engine/evidence_vault.py) 將 Opus 音訊自動寫入 `audio/`，截圖寫入 `images/`，並在資料庫建立案件關聯。
3. **雙軌決策引擎串接（健保合規審核 + 診所自費推薦）**：
   - 調用三方比對引擎比對健保 C 類支付規定與臨床圖譜 [`ClinicalComplianceGuard`](file:///home/hsu/Desktop/Elcinsurrence/SoapVoice/src/nlp/compliance_guard.py)。
   - 即時返回紅黃綠燈合規警示與診所高價值自費品項（PRP / 長效玻尿酸等）。
4. **驗證與測試**：
   - 撰寫單元與整合測試 `tests/test_soapvoice_ingest.py`，模擬 SoapVoice LANClient 上傳完整診次流程。
