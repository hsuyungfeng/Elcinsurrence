# Plan 21-03: 雲端與地端 Local Agent 橋接 API（Bridge API for NHI_EIIAPI）

## 任務目標
1. 建立地端 Agent 橋接資料模型與儲存（Bridge Queue / State Store）：
   - 記錄待上傳任務（Job），包含：
     - `job_id`: 唯一識別碼
     - `job_type` / `s_type_code`: 健保作業代碼（`15`: 費用抽審 XML、`00`: 專業審查病歷影像、`07`: 申復 XML、`09`: 申復預檢）
     - `target_id`: 對應之批次年月或案件 ID
     - `status`: `PENDING` -> `SENDING` -> `SUCCESS` / `FAILED`
     - `local_id`: 地端 Agent 呼叫 NHI_SendA 回傳之 `sLocal_ID`
     - `nhi_id`: 健保 IDC 回傳之 `sNHI_ID` / 執行編號
     - `nhi_status`: `NHI_Query` 狀態（如 `A12: 檔案已就緒`、`A99: 已傳送完成`）
2. 實作 REST API 端點 (`src/elc_audit_engine/api/routes/bridge.py`)：
   - `GET /api/bridge/jobs/pending`：
     - 查詢參數可過濾 `sTypeCode`。
     - 地端 Agent 輪詢拉取待處理任務，並自動附帶下載連結或 Payload。
   - `POST /api/bridge/jobs/<job_id>/status`：
     - 地端 Agent 回報傳送結果，更新 `sLocal_ID`、`sNHI_ID` 與 `nhi_status`。
   - `GET /api/bridge/jobs/<job_id>`：
     - 供雲端前端工作台即時查詢送審進度。
3. 撰寫單元測試：
   - `tests/test_bridge_api.py`：驗證任務建立、拉取佇列、狀態回報與更新閉環。
