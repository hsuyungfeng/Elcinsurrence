# Plan 21-01: 健保標準檔案打包器（Evidence Packager）與單案送審匯出端點

## 任務目標
1. 實作 `src/elc_audit_engine/packagers/nhi_case_packager.py`：
   - 檔名命名規則轉換：第一階代碼(2碼) + 第二階代碼(1碼) + 案件分類(2碼) + 案件流水號(6碼)，多張影像末尾追加數字編號（1, 2, ...）。
   - 格式過濾：禁止直接送審 `.zip`, `.rar`, `.exe`，白名單接受 `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tif`, `.tiff`, `.pdf`, `.txt`。
   - 打包功能：將抽樣案件之病歷 XML（或 PDF）與佐證庫關聯檔案整合成送審資料夾結構。
2. 實作 API 路由：
   - `GET /api/sampling/cases/<case_id>/export-package`：下載該案件之完整送審 ZIP 檔案包（供診所人員檢視或地端 Agent 抓取），落實「單案一次性送審，禁止分拆」。
3. 撰寫單元測試：
   - `tests/test_nhi_case_packager.py`：測試檔名映射（11碼+序號）、禁止格式阻擋、單案檔案整包輸出。
