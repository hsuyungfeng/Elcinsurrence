  <files>deploy/install.sh, deploy/healthcheck.sh</files>
  <action>
完成 install.sh 的互動流程（`--yes` 時取預設、無互動）：
1. check_prereqs：確認 Ubuntu（/etc/os-release ID=ubuntu，非 Ubuntu 只警告，per D-32-03）、`uv` 存在（否則印官方安裝網址並結束，不自動下載）、`systemctl --user` 可用（XDG_RUNTIME_DIR 未設時提示 `export XDG_RUNTIME_DIR=/run/user/$(id -u)`）。
2. sync_deps：`uv sync --no-config`。建立 data/、logs/。
3. detect_trust：執行 `uv run --no-config python -m elc_audit_engine.lan_trust --describe`，顯示偵測到的信任網段與候選介面；依 D-32-16／D-32-17：needs_confirmation 或多候選時要求安裝人員選擇／確認，並把結果寫入環境檔 ELC_TRUSTED_SUBNETS（僅補缺，已設定則顯示既有值並詢問是否沿用）。
4. ask_backup_root：詢問備份目的端掛載點，以 `findmnt -no FSTYPE --target` 顯示檔案系統；exfat 為預期（D-32-11），其他檔案系統顯示提醒但允許；與 data/ 同裝置時拒絕；寫入 ELC_BACKUP_ROOT。未提供時跳過並提醒「狀態頁將顯示尚未設定自動備份」。
5. install_units：渲染到 `~/.config/systemd/user/`，`systemctl --user daemon-reload`，enable --now 主服務、健康檢查 timer、備份 timer（未設 ELC_BACKUP_ROOT 時不啟用備份 timer）。
6. enable_linger：`loginctl show-user "$USER" -p Linger` 已為 yes 則跳過，否則嘗試 `loginctl enable-linger "$USER"`，失敗時印出需以 sudo 執行的指令。
7. ufw：`ufw status` 為 active 時印出建議指令（允許信任網段到 5000/tcp 與 5001/udp），不自動修改防火牆。
8. print_summary（C6）：取主機 IP（同 lan_trust 偵測介面），以 `ip -j -4 addr` 的 `dynamic` 旗標或 `nmcli`／netplan 判斷是否 DHCP，DHCP 時以醒目文字建議在分享器保留固定 IP；最後印出「請在其他電腦開啟 http://<IP>:5000」、「第一次使用請開啟 http://<IP>:5000/setup」、「系統狀態 http://<IP>:5000/status」。
healthcheck.sh：在既有 /api/health 判斷之後，另以 `curl -s --max-time 10 -o "$ROOT/logs/health-deep.json" -w "%{http_code}"` 呼叫 `/api/health/deep`（URL 可由 ELC_HEALTH_DEEP_URL 覆寫），僅在狀態碼由 200 變為 503 或相反時寫一行日誌；不得以 deep 結果觸發重啟。
