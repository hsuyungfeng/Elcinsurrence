## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → 區網任意主機（探測） | 探測請求會送到未知主機，不可帶機密 |
| 使用者輸入 → 手動 URL | 任意輸入可能指向外部或惡意主機 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-10 | Information Disclosure | 探測請求洩漏 API key 或病歷 | mitigate | 探測只送無標頭、無 body 的 GET /api/health；測試攔截驗證 |
| T-30-11 | Spoofing | 偽裝 server 收到 API key | mitigate | 子網與 UDP 候選須使用者確認後才可進入認證流程（由 30-08 實作確認步驟） |
| T-30-12 | Denial of Service | 子網掃描耗盡資源 | mitigate | max_workers<=64、單機逾時 0.5 秒 |
| T-30-13 | Tampering | 手動 URL 指向公網或惡意主機 | mitigate | 只接受私有 IPv4 literal 與 http |
| T-30-14 | Information Disclosure | health 回應新增敏感欄位 | mitigate | 只新增 service 欄位，測試掃描 |
