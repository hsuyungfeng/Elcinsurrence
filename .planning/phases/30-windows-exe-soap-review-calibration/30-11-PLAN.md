<contract>
以下為本計畫定義的雲端契約（客戶端實作依此，伺服端另案實作）。所有 JSON 為 UTF-8，請求與回應本文上限 256 KiB。

契約版本：contract_version = 1。

共同 item 形狀（上傳與下載相同，白名單鍵如下，多出任何鍵即拒絕）：
- item_key：字串，符合 ^[A-Za-z0-9_.-]{1,64}$
- section：必須屬於 SECTIONS
- kind：必須屬於 KINDS
- status：必須屬於 STATUSES
- local_only：布林；selector 為 null 時必為 true
- detected：物件，只允許 role、automation_id、control_type 三鍵
- selector：物件或 null，只允許 role、automation_id、control_type 三鍵；automation_id 為空時 selector 為 null 且 local_only 為 true

（決定：上傳的 detected 與 selector 一律不含 name 與 window_title。即使 automation_id 缺少，也不以 name 作為替代識別碼，以免病患姓名等自由文字進入雲端；該項僅留本機。此決定對應 O-CLOUD-3。）

上傳端點：POST {cloud_base_url}/api/v1/his-calibration/profiles
- 標頭：Content-Type application/json；charset=utf-8、Authorization: Bearer <cloud_token>、Idempotency-Key: <profile_sha256>
- 本文鍵（白名單）：contract_version、vendor_key（^[a-z0-9][a-z0-9_-]{1,31}$）、vendor_version（字串或 null，≤64 字元）、machine_id（UUID4 字串）、calibrated_at（ISO-8601 UTC）、profile_sha256（64 位十六進位）、items
- 不含：calibrated_by、confirmed_by、任何 value、任何 window_title、任何 name（detected 層）
- 回應：200 或 201 視為 accepted；409 視為 accepted（重複，冪等）；408、425、429、5xx、網路錯誤、逾時 視為 retry；其他 4xx 與 3xx（含 redirect，本計畫不跟隨）視為 rejected，移入 failed/。回應本文不解析、不記錄，只記錄 HTTP 狀態碼。

下載端點：GET {cloud_base_url}/api/v1/his-calibration/profiles/{vendor_key}/latest
- 標頭：Authorization: Bearer <cloud_token>、Accept: application/json
- 404：回傳 None（無預校正，走完整精靈）
- 200：本文鍵白名單 contract_version、vendor_key、vendor_version、profile_sha256、calibrated_at、items；任何多餘鍵（包含 readback_test_passed、calibrated、is_ready、value）即拒絕
- 驗證順序：大小上限 → JSON 解析 → contract_version == 1 → vendor_key 與請求相符 → items 數量 ≤ 64 且逐項白名單 → 遞迴掃描無 value 鍵 → profile_sha256 以 profile_content_sha256 重算相符 → assert_no_phi 通過
- 任一失敗：拋 PrecalRejected，呼叫端視為無預校正，不影響精靈

profile_sha256 計算：對 {vendor_key, vendor_version, items} 以 json.dumps(sort_keys=True, separators=(",", ":"), ensure_ascii=False) 序列化後取 SHA-256。不含 machine_id 與 calibrated_at，使相同內容在不同機器得到相同 hash。

本機 outbox 目錄（預設 %LOCALAPPDATA%\ElcAgent\calibration_outbox，開發環境 ~/.elcagent/calibration_outbox）：
- pending/<profile_sha256>.json：{payload、attempts、next_attempt_at、enqueued_at}，payload 即上傳本文
- failed/<profile_sha256>.json：{payload、reason（代碼）、http_status}
- uploaded.json：已 accepted 的 profile_sha256 清單（不含 payload）
- 容量上限 200；超過時 enqueue 拋 OutboxFullError，本機校正仍然有效（已寫入 calibration/）
- 退避：min(60 × 2^(attempts−1), 21600) 秒；attempts 達 50 移入 failed/，reason = "max_attempts"
- outbox 檔與 failed 檔不得含 cloud_token、agent_key、operator_key

urllib 傳輸政策：只允許 https://；例外僅限 127.0.0.1 與 localhost（供測試 fake server）；使用預設憑證驗證；停用 redirect（3xx 直接回傳狀態碼）；timeout 10 秒；回應本文讀取上限 256 KiB + 1 byte，超過即視為錯誤、不解析。
