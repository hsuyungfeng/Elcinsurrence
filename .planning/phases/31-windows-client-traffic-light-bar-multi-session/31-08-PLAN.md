<objective>
SoapVoice 端的分段帳本（manifest）與本機暫存清理規則，並把相關設定寫入設定檔。同時修正既有 LocalStorageManager 佇列滿時丟棄最舊項目的行為（已確認：client/local_storage.py add_pending 第 196–197 行呼叫 _remove_oldest），此行為與 D-31-32 衝突。

Purpose: D-31-30 至 D-31-33 的刪除條件需要可靠的「已確認收到」與「已封存」紀錄。
Output: segment_store.py、temp_cleanup.py、設定欄位與測試。

本計畫定義（31-13、31-15 使用）：
- 目錄結構：{local_cache_dir}/cycles/{cycle_id}/chunk_{seq:06d}.wav、manifest.json、full.wav（31-13 產生）、lan_result.json（31-13 產生）、screenshot.*（31-15 放入）。
- CycleManifest 欄位：cycle_id、created_at、chunks（seq → {sha256, size, acked: bool, server_sha256, acked_at}）、total_chunks（stop 後設定）、finalized（bool）、generation_done（bool）、draft_submitted（bool）、draft_id、archived（bool）、archived_at、last_error。
- SegmentStore(cycles_root: Path)：
  - open_cycle(cycle_id) -> Path（建立目錄與 manifest）
  - register_chunk(cycle_id, seq, path) -> str（計算並記錄 sha256 與大小，回傳 sha256）
  - mark_acked(cycle_id, seq, server_sha256) -> bool（不相符回 False 且不改狀態）
  - pending_chunks(cycle_id) -> list[int]（依 seq 升冪的未 acked）
  - reset_ack(cycle_id, seqs: list[int])（server finalize 回報缺段時，把指定段改回未 acked 以便重傳；31-13 使用）
  - set_context(cycle_id, context: dict)／get_context(cycle_id)（循環開始時的病人與醫師欄位，僅存本機 manifest；31-15 寫入、31-13 讀取）
  - set_total(cycle_id, total)、mark_finalized、mark_generation_done、mark_draft_submitted(draft_id)、mark_archived、set_error(msg)
  - load(cycle_id) -> CycleManifest；list_cycles() -> list[CycleManifest]；unfinished_cycles()（未 archived）
  - 所有 manifest 寫入用 tmp＋os.replace；以 threading.Lock 保護同程序併發（錄音執行緒與上傳執行緒）
- temp_cleanup.enforce_cap(store: SegmentStore, max_bytes: int) -> dict（回傳 {before, after, deleted_files, skipped_reason}）：計算 cycles_root 下所有檔案總量；未超過上限直接返回；超過時依 archived_at 由舊到新，只刪 archived=True 且該檔所屬分段 acked=True 的 chunk 檔，以及該循環在全部分段 acked 後的衍生檔（full.wav、lan_result.json、screenshot）；刪到低於上限即停；manifest.json 保留（紀錄可追溯）。
- LANConfig 新欄位：chunk_seconds（預設 20，夾 15–30）、temp_cache_max_mb（預設 2048，環境變數 SOAPVOICE_TEMP_CACHE_MAX_MB）、control_port（預設 18765，環境變數 SOAPVOICE_CONTROL_PORT）、control_host（固定 "127.0.0.1"，非 loopback 值在 31-15 拒絕）、control_token_path（預設依契約 §1）、cycles_dir 屬性（local_cache_dir/cycles）。
</interfaces>
