<interfaces>
既有（SoapVoice client/audio_recorder.py）：AudioRecorder(output_dir)；CHUNK=1024、CHANNELS=1、RATE=16000；start() -> bool；stop() -> Optional[str]；callbacks on_start、on_stop(path)、on_error(msg)；pyaudio 可能為 None（測試環境）。

新增介面（本計畫定義，31-13、31-15 依此使用）：
- AudioRecorder(output_dir, *, segment_seconds: float = 20.0, frames_per_segment: int | None = None, stream_factory=None)：segment_seconds 夾在 15–30（D-31-19）；frames_per_segment 只供測試覆寫；stream_factory 回傳具 read(n, exception_on_overflow=False)、stop_stream()、close() 的物件，預設使用 PyAudio。
- start_cycle(cycle_dir: Path) -> bool：在 cycle_dir 內從 seq 0 開始寫分段（若目錄已有分段，從最大 seq+1 接續）。
- on_segment: Callable[[int, str], None]：封段後於錄音執行緒呼叫，實作端只能做非阻塞排隊。
- stop() -> Optional[str]：封最後一段（若有 frames）；cycle 模式回傳 cycle_dir 路徑字串並把 self.last_total_segments 設為段數；舊模式（start() 未指定 cycle_dir，自動於 output_dir 建立 audio_{timestamp}_{8hex}/ 子目錄）回傳由 concat_segments 產生的單一 WAV 路徑（檔名維持 audio_{timestamp}_{8hex}.wav 慣例）。
- recover_partial(cycle_dir: Path) -> list[int]：把殘留的 chunk_*.pcm.part 轉為 chunk_*.wav（空檔直接移除 .part 不產生分段），回傳恢復的 seq。
- concat_segments(cycle_dir: Path, out_path: Path) -> Path：依 seq 串接所有 chunk_*.wav 的 PCM frames 為單一 WAV。
- 模組函式 pcm_sha256(paths: list[Path]) -> str：依契約 §2 的 audio_sha256 定義計算（31-13 finalize 使用）。
- 封段寫入方式：讀 .pcm.part 全部位元組 → 寫 chunk_{seq}.wav.tmp（wave 模組）→ flush＋os.fsync → os.replace 為 .wav → 刪除 .pcm.part。
</interfaces>
