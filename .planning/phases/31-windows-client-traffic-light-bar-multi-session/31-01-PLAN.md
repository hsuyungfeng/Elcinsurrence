契約版本字串：elc-p31-ipc/1

§1 本機指令通道（快捷列 → SoapVoice 客戶端程序 client/main.py）
- 位址：http://127.0.0.1:{control_port}，control_port 預設 18765（SoapVoice LANConfig.control_port，可改）。只綁定 127.0.0.1；設定為非 loopback 時 SoapVoice 拒絕啟動控制服務。
- 認證：標頭 X-Local-Token。token 檔位置：Windows 為 %LOCALAPPDATA%\ElcSoapVoice\control_token；其他平台為 ~/.local/share/ElcSoapVoice/control_token。SoapVoice 首次啟動時以 secrets.token_urlsafe(32) 產生；快捷列只讀不寫。比對使用 hmac.compare_digest。缺少或錯誤 → 401。
- Host 標頭必須為 127.0.0.1:{port} 或 localhost:{port}，否則 400（防 DNS rebinding）。
- 錯誤格式：{"error": 代碼, "message": 中文說明}。
- GET /control/v1/status → 200，欄位：contract（固定 elc-p31-ipc/1）、state（IDLE｜RECORDING｜UPLOADING｜GENERATING｜SUBMITTED｜ERROR）、cycle_id（字串或 null）、elapsed_seconds（浮點）、patient_bound（布林，SoapVoice 已擷取病人資訊；不得回傳病人姓名或任何病歷內容，D-31-02）、chunks_total、chunks_acked、chunks_pending（整數）、draft_submitted（布林）、last_error（字串或 null）。
- POST /control/v1/start，body {command_id: 32 位小寫 hex, cycle_id: 32 位小寫 hex} → 200 回傳 status 物件（state=RECORDING）。同一 command_id 重送 → 200 回傳相同結果（冪等）。state 為 RECORDING、UPLOADING、GENERATING 時以不同 cycle_id 呼叫 → 409 {"error":"busy"}，且絕不重設進行中錄音（研究 Pitfall 5）。state 為 IDLE 或 SUBMITTED 才可開始新循環。麥克風無法開啟 → 503 {"error":"recorder_unavailable"}。欄位格式錯誤 → 422。
- POST /control/v1/stop，body {command_id, cycle_id} → 200 回傳 status（state=UPLOADING 或 GENERATING）。cycle_id 與進行中不符 → 409 {"error":"cycle_mismatch"}；未錄音且非重送 → 409 {"error":"not_recording"}；同 command_id 重送 → 200 相同結果。
- POST /control/v1/archived，body {cycle_id} → SoapVoice 先以自身 API key 呼叫 server GET /api/cycles/{cycle_id} 確認 state=ARCHIVED，確認後才在本機 manifest 標記 archived（D-31-33）並回 200 {"cycle_id", "cleanup_eligible": true}；server 未確認或無法連線 → 409 {"error":"not_archived_on_server"} 或 503，本機不標記。

§2 SoapVoice → elc server（皆需 X-API-Key，非 Agent 金鑰；不適用 /api/soap/recordings 的私有 IP 免 key 例外，D-30-09）
- POST /api/cycles/{cycle_id}/chunks：multipart，欄位 seq（從 0 起算整數）、sha256（64 位小寫 hex，對整個 WAV 檔位元組計算）、檔案 audio（.wav，單段上限 4 MiB）。server 重新計算 sha256：不符 → 422。新段 → 201 {cycle_id, seq, sha256, duplicate:false}；同 (cycle_id, seq) 且 sha256 相同 → 200 {..., duplicate:true}；同 seq 不同 sha256 → 409；循環狀態不是 RECORDING 或 AWAITING_DRAFT → 409。客戶端只在回應 sha256 與本機相符時才標記 acked（D-31-30）。
- POST /api/cycles/{cycle_id}/finalize：JSON {total_chunks: ≥1 整數, audio_sha256: 64 hex}。audio_sha256 定義為：依 seq 順序，以 wave 模組 readframes 取出每段 PCM frames 後串接的位元組之 sha256（不含 WAV 標頭）。缺段 → 409 {"error":"missing_chunks","missing":[seq...]}；串接雜湊不符 → 422；成功 → 200 {cycle_id, total_chunks, audio_sha256, upload_complete:true}，server 產出完整音檔 DATA_DIR/cycles/{cycle_id}/full.wav。重送冪等。
- POST /api/cycles/{cycle_id}/draft：JSON {session_id, case_id, patient_ref, visit_date, order_code（可省略）, soap:{s,o,a,p}, transcript: 字串, extras:{summary_zh: 字串, past_history: 字串, suggestions:{icd10:[], orders:[], meds:[]}}}。前提：upload_complete 為真且循環狀態為 AWAITING_DRAFT 或 DRAFT_UNUSABLE，否則 409。同 session_id 重送 → 200 回傳同一 draft_id。成功 → 201 {cycle, draft_id, draft_state}。

§3 快捷列 → elc server（皆需 X-API-Key，使用 AgentSettings.operator_key；Agent 金鑰一律 403）
- POST /api/cycles，body {command_id, machine_id, room_id（可省略）} → 201 {cycle}；同 command_id → 200 同一 cycle；該 machine_id 已有未終結循環 → 409 {"error":"active_cycle_exists","active_cycle_id"}（D-31-16）。
- GET /api/cycles/{cycle_id} → 200 {cycle}；GET /api/cycles?machine_id=… → 200 {cycle 或 null}（回傳該機未終結循環，供重啟還原）。
- POST /api/cycles/{cycle_id}/stop，body {command_id} → RECORDING → AWAITING_DRAFT。
- GET /api/cycles/{cycle_id}/draft[?include_transcript=1] → 200 {cycle_id, draft:{draft_id, version, content_hash, state, soap, quality_issues}, extras, advisory:{icd10_suggestions, order_suggestions, med_suggestions, read_only:true}, transcript（僅 include_transcript=1 時）}；尚無草稿 → 404。
- POST /api/cycles/{cycle_id}/confirm，body {content_hash, soap（可省略，醫師修改後的 s/o/a/p）, reviewer_id（可省略）} → 200 {cycle, draft_id, content_hash}。
- POST /api/cycles/{cycle_id}/archive，body {command_id} → 200 {"status":"archived"｜"already_archived"}；202 {"status":"his_pending"｜"his_retry_queued"}；409 {"status":"not_confirmed"｜"his_failed", "reason"}。
- POST /api/cycles/{cycle_id}/abandon，body {reason_code} → 200 {cycle}；只允許 RECORDING、AWAITING_DRAFT、AWAITING_CONFIRM、DRAFT_UNUSABLE。不刪除任何檔案（D-31-29）。
- POST /api/clients/heartbeat，body {machine_id, machine_name, room_id, bar_state, soapvoice_state, chunks_pending, app_version} → 200 {status:"ok", server_time, notify: null 或 {cycle_id, state, draft_id, draft_version}}。回應不得含 soap、transcript、extras、patient 等鍵（D-31-12）。
- GET /api/clients → 200 {rooms:[{room_id, clients:[{machine_id, machine_name, room_id, display_state, cycle_id, cycle_state, last_seen_at, online, client_subnet, in_clinic_subnet}]}]}，不含病歷內容（D-31-17）。
- GET /clients → 多連線監控靜態頁（僅 HTML，資料以 X-API-Key 透過 /api/clients 取得）。

cycle 物件（無 PHI）：cycle_id, machine_id, room_id, state, draft_id, draft_state, chunks_received, total_chunks, upload_complete, his_state, last_error, created_at, updated_at。

§4 server 循環狀態（D-31-05）：RECORDING、AWAITING_DRAFT、AWAITING_CONFIRM、DRAFT_UNUSABLE、CONFIRMED、ARCHIVING、ARCHIVE_FAILED、ARCHIVED（終態）、ABANDONED（終態）。允許轉換：
- RECORDING → AWAITING_DRAFT、ABANDONED
- AWAITING_DRAFT → AWAITING_CONFIRM、DRAFT_UNUSABLE、ABANDONED
- AWAITING_CONFIRM → CONFIRMED、DRAFT_UNUSABLE、ABANDONED
- DRAFT_UNUSABLE → AWAITING_CONFIRM、CONFIRMED、ABANDONED
- CONFIRMED → ARCHIVING、ARCHIVED、ARCHIVE_FAILED
- ARCHIVING → ARCHIVING、ARCHIVED、ARCHIVE_FAILED
- ARCHIVE_FAILED → ARCHIVING、ARCHIVED

§5 監控顯示狀態（D-31-15）：離線（last_seen 超過 ELC_CLIENT_OFFLINE_SECONDS，預設 15 秒，以 server 時鐘計）優先；其次 RECORDING → 錄音中；AWAITING_DRAFT／AWAITING_CONFIRM／DRAFT_UNUSABLE／CONFIRMED／ARCHIVING／ARCHIVE_FAILED → 待確認；無未終結循環且最近一個循環為 ARCHIVED → 已封存；其他 → 待命。

§6 識別字格式：cycle_id、command_id 為 ^[0-9a-f]{32}$；machine_id 須符合 elc_audit_engine.his_calibration.new_machine_id 的產出格式（執行時讀該函式確定正規式並寫入文件）；room_id 為 1–32 字元的 Unicode 字母、數字、底線或連字號，拒絕而非清洗。

§7 分段參數：預設 20 秒（D-31-19，允許設定 15–30 秒，超出範圍夾回邊界）；格式 16 kHz、mono、16-bit PCM WAV。
