<interfaces>
快捷列本機狀態（BarState，字串常數）：SOAPVOICE_OFFLINE、SERVER_OFFLINE、IDLE、STARTING、RECORDING、STOPPING、UPLOADING、AWAITING_DRAFT、AWAITING_CONFIRM、DRAFT_UNUSABLE、CONFIRMED、ARCHIVING、ARCHIVE_FAILED、INTERRUPTED、ERROR。

ENABLED：IDLE → {red}；RECORDING → {green}；CONFIRMED → {yellow}；ARCHIVE_FAILED → {yellow}；其他 → 空集合。

project(server_cycle: dict|None, sv_status: dict|None, *, server_online: bool, sv_online: bool, pending_action: str|None) -> BarState，規則依序：
1. pending_action 為 "starting"／"stopping"／"archiving" 時回 STARTING／STOPPING／ARCHIVING（按下後到回應前全部停用，防雙擊，研究 Pitfall 9）。
2. not sv_online → SOAPVOICE_OFFLINE；not server_online → SERVER_OFFLINE。
3. server_cycle 為 None：sv_status.state 為 RECORDING（SoapVoice 仍在錄、server 無循環）→ INTERRUPTED（研究 Pitfall 8，不得靜默丟棄）；否則 IDLE。
4. server_cycle.state：RECORDING → RECORDING（若 sv_status.cycle_id 不等於 server cycle_id 或 sv 非 RECORDING → INTERRUPTED）；AWAITING_DRAFT → 若 sv chunks_pending > 0 或 sv state 為 UPLOADING → UPLOADING，否則 AWAITING_DRAFT（D-31-23「上傳中」）；AWAITING_CONFIRM、DRAFT_UNUSABLE、CONFIRMED、ARCHIVING、ARCHIVE_FAILED 直接對應；ARCHIVED、ABANDONED 視同無循環（回到規則 3）。
5. sv_status.state 為 ERROR 且 server 循環非終態 → ERROR（附 last_error）。

status_text(bar_state, sv_status, server_cycle) -> str：中文短句，例如「待命」「錄音中 03:12（已綁定病人）」「上傳中 4/7」「等待草稿」「請確認草稿」「草稿品質未通過，請在確認視窗修改」「可封存」「HIS 寫入中」「封存失敗：{原因}，可再按黃燈重試」「SoapVoice 未連線」「server 未連線」「錄音中斷，請至 server 監控頁處理」。不得包含病人姓名或任何 SOAP 內容。
</interfaces>
