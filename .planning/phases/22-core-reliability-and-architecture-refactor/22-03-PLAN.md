# Plan 22-03: 工具鏈與 CI 流程健全化（P1-13, P1-14）

## 任務目標
1. **補全執行期 Runtime Dependencies（P1-13）**：
   - 檢視 `pyproject.toml`，目前 `pypdf`、`Pillow` 被 `attachment_store.py`、`pdf_exporter.py`、`image_processor.py` 直接引用，但在乾淨環境執行 `uv sync --no-dev` 時可能遭遇 ImportError。
   - 將 `pypdf>=4.0.0` 與 `Pillow>=10.0.0` 明確納入 `dependencies`。

2. **配置現代程式碼品質工具鏈（P1-14）**：
   - 在 `pyproject.toml` 中配置 `[tool.ruff]`：
     - `target-version = "py312"`
     - `line-length = 100`（或 120，契合目前風格）
     - `select = ["E", "F", "W", "I", "B"]`，忽略已知既有風格約束。
   - 配置 `[tool.pytest.ini_options]` 補強測試覆蓋率設定（`pytest-cov`）。

3. **建立 GitHub Actions CI 工作流程（P1-14）**：
   - 建立 `.github/workflows/ci.yml`：
     - 觸發條件：`push` 及 `pull_request` 至 `main` 與 `feat/*` 分支。
     - 測試環境：`ubuntu-latest`、Python 3.12。
     - 執行步驟：
       1. `actions/checkout@v4`
       2. 安裝 `uv`（`astral-sh/setup-uv@v3`）
       3. `uv sync --locked`
       4. `uv run ruff check .`
       5. `uv run pytest tests/`

4. **測試與驗證**：
   - 本地執行 `uv run ruff check .` 並修復關鍵語法警示。
   - 本地驗證 CI 腳本與 pytest 順暢運行。
