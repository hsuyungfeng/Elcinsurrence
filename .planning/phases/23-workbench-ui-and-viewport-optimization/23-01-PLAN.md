# Plan 23-01: 工作台極大化佈局、F11 全螢幕沉浸模式與側欄組件浮動最小化

## 任務目標
1. **F11 全螢幕模式切換與快捷鍵監聽（雙向切換）**：
   - 在頂部標頭導覽區新增「⛶ 全螢幕 (F11)」按鈕，點擊觸發 `document.documentElement.requestFullscreen()`；若當前已為全螢幕則執行 `document.exitFullscreen()`。
   - 監聽全域 `keydown` 事件捕捉 `F11` 鍵，攔截預設行為並切換全螢幕模式，支援再次按下 `F11` 或 `Esc` 回復原狀。
   - 監聽 `fullscreenchange` 事件，動態切換按鈕圖示與文字（「⛶ 全螢幕」↔「🗗 視窗」）。

2. **左側側欄寬度縮半（280px -> 140px~150px）與高密度排版**：
   - 調整 `main` 佈局之 `grid-template-columns` 由 `280px 1fr` 調整為 `140px 1fr`（在寬螢幕下亦支援快速切換或摺疊）。
   - 重構 `.case-item` 樣式為高密度緊湊膠囊：字級、行高與內距最佳化，流水號與醫令/狀態以 Mini Badge 呈現。
   - 引入浮動字幕（Floating Tooltip）：當滑鼠懸停於案件清單項時，浮動顯示病患姓名、身分證字號、主診斷、完整醫令名稱與總費用點數，免除擠壓側欄文字。

3. **左側輔助區塊最小化為浮動字幕／精簡徽章**：
   - 原「機構代碼、院所名稱、費用月份、免重複驗證」大區塊改為頂部一行式精簡狀態膠囊（Compact Status Bar），滑鼠懸停顯示完整院所地址與負責醫師浮動提示。
   - 原佔據大版面的「⚙️ 自訂 API Key」與「📚 規則庫管理」預設折疊為收納式小圖示按鈕，點擊展開浮動面板或對齊底部，使側欄 90% 以上空間完全留給案件清單捲動。

4. **1. 2. 3. 階工作台介面規格與尺寸完全統一**：
   - 檢視並校正 `workflow1View`（第 2 階抽審）、`workflow2View`（第 3 階申復）、`workflow3View`（第 1 階月審）的外層容器、面板圓角、標題列尺寸與雙欄 `card-grid`。
   - 右側工作區寬度大幅增加（增加約 140px），確保 SOAP 編輯區、佐證庫照片、給付規定條文與審核報告獲得最大閱讀與操作視野。

5. **測試與向後相容驗證**：
   - 確保現有 `tests/test_ingest.py` 之前端無外鏈規範（`test_frontend_has_no_external_resource_links`）、無危險 innerHTML 模板（`test_frontend_case_list_does_not_use_innerhtml_templating`）持續 100% 通過。
   - 驗證三軌切換功能、案件載入與點擊、院所設定彈窗與單案鍵入彈窗一切正常。
