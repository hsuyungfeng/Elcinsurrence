# Phase 23: 工作台視覺佈局極大化與沉浸式操作優化 (Workbench UI & Viewport Optimization)

## 背景與痛點
使用者在長時間審查與比對臨床病歷、申復理由草稿時，受限於目前的版面配置：
1. **左側欄佔幅過寬**：目前左側清單欄為 `280px`（約佔螢幕近 1/4），導致右側核心工作區（包含兩欄並排卡片、SOAP、給付規定、佐證庫）顯得壅擠。
2. **缺乏全螢幕專注沉浸模式**：在查看長篇病歷或多源影像佐證時，受限於瀏覽器網址列、標頭導覽列，缺乏一鍵 F11 全螢幕快速切換機制。
3. **資訊過載與次要區塊佔位**：左側「院所檔案」、「月份驗證」、「自訂 API Key」、「規則庫同步」等輔助元件長期佔據縱向垂直高度，壓縮了病患與案件清單的可視行數。
4. **三軌工作台規格不一致**：第 1 階（當月申報預審）、第 2 階（抽審事前預審）、第 3 階（核減事後申復）在視覺佈局、邊界間距與最大化使用體驗上應保持 100% 相同規格。

## 使用者核心需求
1. **F11 全螢幕快捷切換**：
   - 支援鍵盤按下 `F11` 進入全螢幕沉浸模式，再按一次 `F11`（或 `Esc`）平順退出全螢幕並恢復原視窗比例。
   - 介面右上角/頂部新增「⛶ 全螢幕」視覺化按鈕，方便滑鼠操作，支援全螢幕狀態即時切換與 tooltip 提示。
2. **左側輔助元件最小化／浮動字幕化**：
   - 將「🏥 機構代碼」、「📅 申報月份（免重複驗證）」、「✏️ 院所設定」、「⚙️ 自訂 API Key」、「📚 規則庫管理」等輔助區塊最小化為精簡狀態列、浮動字幕或可收折小膠囊（Badge/Floating Tooltip）。
   - 保留快速點擊彈窗編輯與查看功能，但預設釋放 80% 以上垂直空間給「案件清單」顯示。
3. **左側欄寬度縮半（極大化右側作業位置）**：
   - 將左側清單寬度從目前 280px 縮減一半（約 140px~150px），或改為高密度 Compact Mini Sidebar。
   - 案件標籤、流水號、病患識別採緊湊排版，滑鼠懸停（hover）以精緻浮動字幕（Tooltip）展示完整資訊。
   - 藉此極大化右側核心工作區寬度，讓第 1、2、3 階的工作台、SOAP 臨床病歷、影像佐證與審核報告獲得最大視野。
4. **1. 2. 3. 階介面規格全面一致**：
   - 當月申報預審、抽樣事前預審、核減事後申復，三軌版面尺寸、左右比例、全螢幕行為與卡片容器高度保持一致。
