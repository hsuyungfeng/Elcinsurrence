## 二、工作項目

### 工作 A：Ruff 規則回復（先做，風險低）
- **A1** 自 `pyproject.toml` 的 `ignore` 移除 `F841`、`B007`，修正 22 處違規。修正原則：
  - 未使用變數：刪除或改為 `_` 前綴；**不得**為了通過而改變行為。
  - 未使用迴圈變數：改為 `_`。
- **A2** 移除 `tests/**` 的 `F811` 豁免。若 fixture 覆寫匯入名稱確實必要，逐行加 `# noqa: F811` 並註明原因，不得整檔豁免。
- **A3** 保留 `ignore` 內其餘項目（`B008`、`B904`、`B905`、`I001`），它們在註解中已有理由，本階段不擴大範圍。
- **驗收**：`ruff check .` 通過；`pyproject.toml` 的 `ignore` 僅剩 `B008`、`B904`、`B905`、`I001`。

### 工作 B：CSP `style-src` 嚴格化
- **B1** 靜態頁（`clients.html`、`setup.html`、`status.html`）：
  - 將 `style="..."` 改為 CSS class，樣式移至 `static/css/` 下對應檔案（新增 `setup.css`、`status.css` 等，或併入既有 `workbench.css`）。
  - 將 `<style>` 區塊移出，改為外部樣式表。
- **B2** Python 生成的 HTML（`monthly_report_html.py`、`sampling_preview.py`、`services/report_renderer.py`、`emr_review_bundle.py`、`monthly_package.py`）：
  - **需先確認**：這些 HTML 是「由 app 直接在瀏覽器開啟」還是「匯出為獨立檔案」。
  - 若為**獨立匯出檔**：app 的 CSP header 不適用於其內容，這類檔案的 `<style>` 可保留，但須在 `CLINIC_DEPLOYMENT_GUIDE.md` 或程式註解中如實標注「不受 app CSP 約束」。
  - 若為**app 直接提供**：改用外部 CSS 檔（同源 `/static/...`），並移除 `style=` 屬性。
  - 預設採上述第一種，並將決定寫入 `AGENTs.md` 第 2 節。
- **B3** `on*=` 事件屬性（3 處）：改為 `addEventListener`，或由外部 JS 綁定。
- **B4** 收緊 CSP：`security.py` 的 `style-src` 改為 `'self'`（視 B2 的結果，若獨立匯出檔不經此 header，則可直接收緊）。
- **驗收**：
  - 全套件測試通過（目前基準 1649 passed、2 skipped、1 deselected）。
  - 瀏覽器實測 `/`、`/setup`、`/status`、`/clients`：console 無 `Refused to apply inline style` 或 `Refused to execute inline event handler` 錯誤。
  - `grep -rn 'style="' static` 與 `grep -rn '<style' static` 無結果（或僅剩已註明的獨立匯出檔）。

### 工作 C：文件與狀態更正
- 更正 `STATE.md` 與 `PHASE32-COMPLETION-REPORT.md`：`style-src` 仍含 `'unsafe-inline'` 的實際狀態，以及 292 → 17 的數字修正。本階段完成後改為「已嚴格化」。
