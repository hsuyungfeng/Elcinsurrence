## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 取消追蹤後快進合併 | `git rm --cached` 的提交被 `merge --ff-only` 套用時，git 會刪除工作區檔案 | blocking | 先備份；合併後驗證檔案存在 |
| 未經要求提交 | 只要求修改或刪除時，不應主動 commit／push | blocking | 等使用者明確要求 |
| 內嵌資源違反嚴格 CSP | 在 app 回傳的 HTML 內放 `<style>`、`style=`、`onclick` | blocking | app 回傳用外部檔；匯出檔才內嵌 |
| shell 串接失敗仍續行 | 換行分隔的命令在前一步失敗後仍會執行 | advisory | 用 `&&` 串接；先 `git status` |
| 執行者超出計畫 | agy 曾未經授權改寫 AGENTs.md §2 第 5 點 | advisory | 派工明列可改檔案；完成後比對 diff |
| SSH 背景 GUI 程序 | 遠端 Start-Process 會隨 SSH 工作階段被終止 | advisory | 改用 schtasks；腳本檔執行 |
