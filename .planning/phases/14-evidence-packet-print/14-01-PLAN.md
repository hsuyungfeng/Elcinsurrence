# Plan 14-01: Evidence Packet DOCX Builder & Image Processor

<threat_model>
- **T-14-01: PHI 個資防護與本地零外洩 (Zero-SaaS Privacy & Local Execution)**: All image processing and DOCX rendering occurs purely locally using `python-docx` and `Pillow`. No external services or API calls are used to process PHI or generate the packet.
- **T-14-02: 損毀或假造影像檔例外處理 (Corrupted/Malformed Attachment Defense)**: Handled in `image_processor.py`. `Pillow` exceptions during image load or processing are caught and gracefully degraded to a warning callout box in the DOCX rather than crashing the process.
- **T-14-03 / T-14-04**: Deferred to export/CLI layers (Plan 02).
</threat_model>
