# Plan 17-02: 前端第二階介面升級（身分證佐證庫多源掛載與多媒體預覽）

## 目的
升級前端抽審工作台介面，依選取案件的身分證字號與就醫年月自動掛載對應之 Vault 佐證資料夾，提供相片圖檔畫廊、錄音檔直接播放器、檢驗報告與病歷對照檢視。

## 任務清單
1. **升級前端抽樣/抽審介面佈局 (`static/index.html`)**:
   - 頂部或案頭顯示：`📁 佐證庫：A123625499-2605` 與快速上傳按鈕（支援拖曳或上傳檔案/ZIP）。
   - 增加 **多媒體佐證卡片區**：
     - 🎙️ **錄音播放器**：若 Vault 內有音訊檔，直接渲染 HTML5 `<audio controls>` 播放條。
     - 🖼️ **影像畫廊 (Gallery)**：縮圖預覽、支援點擊彈窗放大（LightBox）檢視手術/創傷相片。
     - 📄 **檢驗/檢查報告**：列出 PDF 報告並提供預覽或點擊下載連結。
2. **自動連動與案件切換**:
   - 點選左側抽審清單時，自動解析案件的 `record_no` (身分證號) 與 `visit_date` (民國年月 YYMM)。
   - 自動向 `/api/vault/<vault_key>` 發送請求並渲染多媒體卡片。
   - 若資料夾尚無檔案，顯示友善提示：「尚未匯入 A123625499-2605 佐證檔案，可拖曳 ZIP 或單檔至此」。
3. **前端功能自測**:
   - 確保無 JS error，XSS 安全轉義完整，不引進外部 CDN。
