# Plan 16-02: 多源證據（檢驗、雲端病歷、影像）輸入與視覺化 HTML 預覽 API

## 目的
讓抽樣預審案件具備「多源數據輸入」與「即時視覺化 HTML 預覽」，支援影像附件上傳與雲端病歷、檢驗報告維護。

## 任務清單
1. **擴充 Sampling 案件多源資料結構** (`src/elc_audit_engine/parsers/models.py` 與 `store.py`):
   - 在 `SamplingCaseRecord` 與 payload 中擴充：
     - `lab_results`: 檢驗數據清單（例如 HbA1c: 8.2%, AC Sugar: 185 mg/dL 等）。
     - `cloud_records`: 跨院雲端病歷摘要文字。
     - `attachments`: 關聯的影像附件清單。
2. **多源資料更新與附件上傳 API**:
   - `PUT /api/sampling/cases/<case_id>/evidence`: 更新案件的檢驗數據與雲端病歷文字。
   - 擴充 `POST /api/attachments/upload`：允許為 `kind='sampling'` 的 `case_id` 上傳佐證圖檔與報告。
3. **視覺化 HTML 預覽 API** (`GET /api/sampling/cases/<case_id>/preview-html`):
   - 產出類似電子公文/審查卡片的美觀 HTML 預覽：
     - 病患基本資料（就醫日、科別、病歷號）
     - 4 欄 SOAP 病歷（S, O, A, P）
     - 🧪 檢驗數據卡片
     - ☁️ 雲端跨院紀錄卡片
     - 🖼️ 影像附件縮圖與報告說明
4. **回歸測試** (`tests/test_sampling_evidence_preview.py`):
   - 驗證 API 讀寫與 HTML 渲染正確。
