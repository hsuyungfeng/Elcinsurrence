# Plan 16-03: 前端 UI 整合（多源輸入、自動化審核與健保局 XML 導出）

## 目的
在前端「抽樣事前預審」介面中整合多源資料輸入、Qwen3.8-27B 智慧審核補強、HTML 視覺化預覽，並提供回傳健保署規格之 XML 導出功能。

## 任務清單
1. **健保抽審 XML 導出器** (`src/elc_audit_engine/generators/sampling_xml.py` 與 `GET /api/sampling/cases/<case_id>/export-xml`):
   - 依照健保署電子抽審規範，組裝 XML：
     - `<tdata>`: 院所與申報基本資料
     - `<ddata>`: 案件主檔、診斷、就醫紀錄
     - `<pdata>`: 抽審醫令項目
     - `<soap>`: 完整 S/O/A/P 臨床紀錄
     - `<attachments>`: 佐證附件（檔名、類型、Hash/Base64）
2. **前端 HTML/UI 功能升級** (`static/index.html`):
   - 在 Workflow 1（抽樣事前預審）新增：
     - 「📦 從申報總檔自動抽樣 (20隨機+10立意)」按鈕。
     - 🧪 檢驗數據（Lab Results）編輯卡片。
     - ☁️ 雲端病歷（Cloud EHR）編輯卡片。
     - 🖼️ 影像上傳與即時預覽元件。
     - 「🔍 檢視視覺化預審卡片 (HTML)」按鈕與彈窗。
     - 「📄 導出健保局抽審 XML」按鈕。
3. **LLM 智慧審核與自動補強銜接**:
   - 確保 `14050B`、`64140C` 等案件在點擊「⚡ 審核病歷並評估支持度」時，LLM 同步參考 SOAP、檢驗、雲端病歷與給付規定。
   - 產出缺口分析（如 HbA1c 追蹤頻率、數值標註）與智慧補強建議，並可一鍵套用。
4. **端到端驗證** (`tests/test_sampling_workflow_e2e.py`):
   - 測試抽樣 → 填寫多源證據 → LLM 審核補強 → 導出 XML 的完整閉環。
