# Phase 16: 事前預審抽樣清單與多源審查工作台 (Sampling Pre-submission Workbench)

## 階段目標
實作「事前預審抽樣清單」自動化抽樣、多源證據（SOAP / 檢驗數據 / 雲端病歷 / 影像附件）整合審查、LLM 智慧補強與健保局格式 XML 導出。

## 核心需求架構
1. **抽樣清單生成演算法**（基於申報總檔 `MONTHLY-202307`）：
   - 隨機抽樣：隨機選取 20 本案件。
   - 立意抽查：選取前 3 個高價醫令點數合計最高（或最高單價）的 10 本案件。
   - 合併形成 30 本（20+10）正式抽樣預審清單，並支援匯入 `CaseStore(kind='sampling')`。
2. **多源資料輸入與視覺化 HTML 預覽 API**：
   - 支援線上輸入／匯入：
     - 門診 SOAP 病歷（S/O/A/P 結構）
     - 檢驗報告數據（Lab Results，如 HbA1c 數據）
     - 健保雲端跨院病歷紀錄（Cloud EHR Sync）
     - 影像佐證上傳（圖片 / DICOM / 報告截圖）
   - 即時視覺化 HTML 預覽卡片，支援動態更新。
3. **LLM 智慧審核與自動補強機制**：
   - 針對抽樣案例（如 `14050B - 糖化血色素檢驗 HbA1c` 或其他醫令）進行給付規範比對。
   - 針對缺口提出具體補強建議（如：建議補強「上次 HbA1c 數值與例行評估說明」）。
   - 支援「一鍵套用至病歷」並保存至資料庫。
4. **健保抽審 XML 導出**：
   - 產出符合健保署抽審規格的 XML 格式（含門診處方、診斷、完整 SOAP 記載與附件佐證關聯檔案）。
