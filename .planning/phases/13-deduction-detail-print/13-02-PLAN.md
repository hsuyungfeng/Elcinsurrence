# Phase 13-02: ODT Filling & PDF Rendering Engine

## Goal

Implement the dynamic XML modification layer for ODT documents and integrate LibreOffice headless conversion to produce the final PDF printout.

<threat_model>
- **T-13-01**: ElementTree XML 轉義 (XSS/XML Injection 防禦) - Ensure cell content injection uses `p.text = val` instead of manual string assembly.
- **T-13-03**: safe_filename() 檔名路徑穿越防護 (Path Traversal Protection) - Use `safe_filename` in output routines.
- **T-13-04**: 暫存檔隔離與即時清除 (Temp Directory & Product Isolation) - ODT rendering steps done in `TemporaryDirectory`.
</threat_model>
