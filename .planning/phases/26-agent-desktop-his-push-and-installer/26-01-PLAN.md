# Plan 26-01: Agent-Desktop 原生 HIS 自動寫入與 ClinicClientInstaller 封裝

## 任務目標
1. **整合 `vercel-labs/agent-desktop` Windows UIA 自動化**：
   - 封裝 Python `ctypes` 接口調用 `libagent_desktop_ffi.dll`（或 CLI `agent-desktop.exe`）。
   - 實作 Observe–Act–Verify 閉環：透過 `snapshot -i` 取得 Accessibility Tree 與 `@ref` 標籤，透過 UIA `ValuePattern` 執行無頭背景寫入，不搶奪醫師滑鼠焦點。
2. **HIS 適配範本與 `STALE_REF` 重試狀態機**：
   - 建立 `his_profiles.json` 針對展望、耀聖、佲格、志氏提供欄位配置與 Calibration 精靈。
   - 遇到控制項重繪時自動處理 `STALE_REF` 刷新快照，並提供剪貼簿貼上與浮動卡片兜底策略。
3. **BridgeQueue `HIS_PUSH` 任務處理器**：
   - 監聽 `BridgeQueue` 中 `s_type_code="HIS_PUSH"` 任務，使用 CAS 樂觀鎖更新狀態為 `SENDING`，執行寫入並回報 `SUCCESS`/`FAILED`。
4. **診間客戶端整合安裝包 (`ClinicClientInstaller.exe`)**：
   - 封裝 Little B 浮動視窗、SoapVoice Client、`agent-desktop` 與 WebBrain 擴充套件服務為單一安裝執行檔。
