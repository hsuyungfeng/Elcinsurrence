# Phase 12 Plan 01: Attachment Store & API Integration

## Goal
Establish the backend infrastructure for uploading, securely validating, storing, and associating evidence images with specific case sequences. Dynamically drive the `p7` (has_attachment) flag based on the actual existence of these files.

## Threat Model
<threat_model>
- T-12-01: 路徑穿越 (Path Traversal) 上傳危害 -> safe_filename 白名單防禦
- T-12-02: 假造副檔名/惡意/損毀檔案 -> Magic Bytes + 開檔驗證
- T-12-03: PHI / 敏感個資檔名洩漏 -> 審計日誌只記操作不留檔名內容
- T-12-04: 不具名或非法 API 存取 -> 呼叫權限與 safe_filename() 校驗
</threat_model>
