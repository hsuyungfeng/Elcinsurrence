# Plan 25-01: WebBrain 健保 VPN 雲端藥歷 2.0 預讀與三軌自動化工作流

## 任務目標
1. **整合 WebBrain Local MCP Bridge (`ws://127.0.0.1:17374/extension`)**：
   - 封裝 Python 客戶端 `src/elc_audit_engine/webbrain_bridge.py`，透過 WebSocket 連接 `@webbrain/mcp-server`。
   - 支援 Protocol v2 握手、驗證 Pairing Key，並提供高階方法調用。
2. **健保雲端藥歷 2.0 結構化擷取 (`webbrain_extract` mode="ask")**：
   - 定義健保雲端藥歷 JSON Schema（`nhi_med_history`, `recent_labs`, `duplicate_alerts`）。
   - 在唯讀模式下精準擷取近 6 個月跨院門診處方與檢驗檢查（HbA1c / LDL-C / eGFR / Creatinine），並提供 PIN 碼人工交接確認（`run_handoff_v1`）。
3. **雲端藥歷資料自動注入時間軸與 Objective 段落**：
   - 將擷取的檢驗值與日期自動填入當前案件之 SOAP `O` 段。
   - 於三方比對引擎中執行重複用藥即時攔截，消滅健保核刪爭議點。
4. **工作台 Stage 1/2/3 語意化按鈕 E2E 自動化驗收**：
   - 利用 `static/index.html` 之語意化 `data-test-id` 撰寫自動化巡檢腳本，驗證二階（13 顆按鈕）與三階（11 顆按鈕）操作流。
