# Plan 27-01: 診間即時 SOAP 工作台、護理錄製監控與司法病歷金庫 UI (Beautiful UI)

## 任務目標
1. **頂部導覽四軌分頁擴充（4th Tab）**：
   - 於 [`static/index.html`](file:///home/hsu/Desktop/Elcinsurrence/static/index.html) 的 `.mode-switcher` 擴充第 4 顆頁籤：
     `🎙️ 4. 診間即時 SOAP (錄製監控 / 結構化病歷 / 法院證據包)`。
   - 擴充 `switchWorkflowMode('soap')` 狀態切換，無縫融入 Phase 23 的高密度極大化佈局與 F11 全螢幕沉浸模式。

2. **左側雙層佈局（歷史病患檢索 ＋ 護理專員即時錄音監控台）**：
   - **上半部（病患檢索與日期時間軸）**：
     - 提供「身分證字號」與「出生年月日」雙檢索欄位，支援快速模糊搜尋。
     - 查詢後展示歷次門診時間軸卡片（包含看診日期、主訴標題、生檔數量標籤）。
     - 點選任一門診日期，右側即時切換載入該次門診之 SOAP 與金庫生檔。
   - **下半部（護理專員即時錄製監控台）**：
     - 顯示當前診間正在錄製之病患卡片（姓名、身分證號、就醫序號）。
     - 🔴 錄音狀態動態呼吸燈（Pulsing Indicator）與即時通話秒數計時器。
     - CSS 聲波視覺化動態條（Audio Waveform Animation）。
     - 即時 ASR 逐字稿浮動字幕滾動條（Live Transcript Subtitle Ticker），呈現問診對話流。

3. **右側主工作區（結構化 SOAP Form ＋ 司法/法院調閱佐證金庫）**：
   - **結構化 SOAP Form**：
     - 精緻卡片式 `S`（主訴）、`O`（客觀檢查，含 WebBrain 雲端藥歷）、`A`（ICD-10 與診斷）、`P`（處方處置與自費推薦）高對比編輯區。
     - 提供一鍵「📋 複製完整 SOAP」與「📤 寫入 HIS（agent-desktop UIA 背景回填）」。
   - **生檔檔案庫與司法佐證包（Forensic Evidence Vault）**：
     - 🎙️ 原始問診錄音（Opus/WAV 內建 HTML5 音訊播放器）。
     - 🖼️ 醫療影像／截圖縮圖畫廊（支援點擊放大燈箱）。
     - 📑 檢驗報告與就診單據列表。
     - **一鍵打包下載法院/審查專用佐證包（ZIP）**：
       - 內含：結構化病歷書面文字檔（`SOAP_RECORD.txt`）、原始音訊影像檔、`SHA256_CHECKSUM.txt` 數位防竄改指紋、`AUDIT_TRAIL.json` 存取審計時間戳記，供法庭訴訟保全證據與健保訪查使用。

4. **後端 API 支援（`his_integration.py` & `evidence_vault.py`）**：
   - `POST /api/soap/search-patient`：查詢歷史病患歷次門診紀錄。
   - `GET /api/soap/live-session`：取得護理專員目前即時錄製狀態與逐字稿文字流。
   - `GET /api/soap/cases/<case_id>/bundle`：取得特定就診紀錄之 SOAP 與金庫檔案清單。
   - `GET /api/soap/cases/<case_id>/export-forensic-zip`：打包下載司法/審查專用防竄改佐證包 ZIP。

5. **測試與驗證（`tests/test_soap_workbench_ui.py`）**：
   - 驗證病患查詢、即時串流、司法佐證包 ZIP 打包（含 SHA-256 數位指紋）及前端元素無外鏈、DOM-Safe 等規範 100% 通過。
