None dropped or descoped. All three requirements as originally scoped in ROADMAP.md Phase Details were delivered. REQ-evidence-packet-print required one post-hoc correctness fix (case_seq/case_id key mismatch) before being confirmed satisfied — see `v1.1-MILESTONE-AUDIT.md` for full defect analysis and fix record.

## Requirement Outcomes Detail

- **REQ-attachment-upload** — `src/elc_audit_engine/attachment_store.py` (Magic Bytes validation, path sanitization, 10MB limit, HEIC support via `pillow_heif`), 3 new Flask routes, dynamic `has_attachment` driver in `generators/appeal.py`. No gaps.
- **REQ-deduction-print** — `src/elc_audit_engine/generators/deduction_print/` (ODT ElementTree dynamic row expansion + soffice headless PDF), `scripts/build_deduction_print.py` CLI, `POST /api/deduction/print`. Known non-blocking tech debt: ODT template (`RCPI2012R01_核減明細表_print_base.odt`) is a hand-built scaffold, not the real NHI official form — swap pending acquisition of the real form.
- **REQ-evidence-packet-print** — `src/elc_audit_engine/generators/evidence_packet/` (python-docx builder + Pillow image processor + pypdf concatenation), `scripts/build_evidence_packet.py` CLI, `POST /api/appeal/evidence-packet/print`. Fixed defect: attachment lookup now uses `case.case_seq` (falling back to `case_id`-derived key only when `case_seq` is empty/None).
