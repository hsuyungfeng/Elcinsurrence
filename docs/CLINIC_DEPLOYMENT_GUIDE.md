# 智慧門診病歷審核系統 — 診所現場安裝與維運指引 (CLINIC DEPLOYMENT GUIDE)

本手冊供診所現場系統工程師、特約維運廠商或資訊人員進行伺服器部署、診間用戶端安裝與日常維護排錯使用。

## 一、系統架構與網路環境要求

```
                                ┌──────────────────────────────────────────────┐
                                │             診所區域網路 (LAN)                │
                                │   信任網段（例如 192.168.1.0/24）               │
                                └──────────────────────┬───────────────────────┘
                                                       │
                 ┌─────────────────────────────────────┴─────────────────────────────────────┐
                 │                                                                           │
        ┌────────┴────────┐                                                         ┌────────┴────────┐
        │  Ubuntu 伺服器   │ (主機端，固定 IP)                                         │ Windows 客戶端   │ (診間各工作站)
        │  - Audit Engine │ HTTP API :5000 (LAN Trust)                              │  - 桌面快捷列   │ (紅綠黃燈)
        │  - UDP Responder│ UDP :5002 探索回應                                      │  - 系統匣圖示   │ (背景常駐)
        │  - 增量備份服務 │ 每日離峰備份至外接碟                                     │  - SoapVoice    │ (免配置純錄音)
        └────────┬────────┘                                                         └─────────────────┘
                 │
        ┌────────┴────────┐
        │ 外接備份隨身硬碟 │ (exFAT / NTFS，零刪除累加)
        └─────────────────┘
```

### 1. 網路拓撲要求
* **同一區域網路**：主機與各診間電腦必須連接至同一個診所區域網路（支援 UDP 廣播 `255.255.255.255:5002` 自動搜尋）。
* **防火牆規則**：主機內部需放行 TCP `5000`（Web API）與 UDP `5002`（探索回應）。
* **信任網段**：伺服器預設自動偵測區網網段，所有在信任網段內的連線免金鑰即可存取。
* **剩餘風險說明（D-32-24）**：同一網段內的任何裝置皆可讀取病歷資料，系統不做逐裝置身分驗證。此為院內網路下已接受的風險。跨站請求已拒絕（D-32-18），管理設定（D-32-27）同網段可直接修改。若日後要收緊，須另立決策。
* **資安防護與 CSP（內容安全策略）**：
  * 主機 Web 介面（`/`、`/status`、`/setup`、`/clients`）全面採用嚴格 HTTP CSP 標頭（`default-src 'self'`, `script-src 'self'`, `style-src 'self'`），不放行任何外部網路資源或未授權 inline 腳本與樣式。
  * 系統匯出／下載之報表與封包（如當月預審報告、抽樣預審卡片、電子病歷審查包等）為單一自包含離線 HTML 檔案，供審查與封存閱覽，不受應用程式 HTTP CSP 約束。

## 二、主機端部署流程（Ubuntu 22.04 / 24.04 LTS）

### 步驟 1：取得部署套件
將安裝檔放置於主機家目錄或指定工作目錄：
```bash
cd /home/elc/Elcinsurrence
```

### 步驟 2：執行自動化安裝腳本
執行安裝程式（全自動建立 python 虛擬環境、下載相依套件與安裝 systemd 服務）：
```bash
bash deploy/install.sh
```

### 步驟 3：設定備份硬碟（重要：D-32-04 零刪除保全原則）
1. 將外接備份硬碟插入主機 USB 埠（建議格式化為 **exFAT** 或 **NTFS**）。
2. 在 `/etc/elc-audit-engine.env` 或執行期環境變數設定掛載路徑：
   ```bash
   echo "ELC_BACKUP_ROOT=/media/backup" | sudo tee -a /etc/elc-audit-engine.env
   ```
3. 啟動並排程每日自動增量備份：
   ```bash
   systemctl --user enable --now elc-backup.timer
   ```
   > ⚠️ **零刪除機制保證**：本系統備份腳本嚴格禁止 `--delete`、`rm -rf` 與硬連結相依性，完全相容 exFAT 檔案系統，確保歷史病歷與生檔絕不遭意外抹除。

### 步驟 4：驗證服務健康狀態
```bash
bash deploy/healthcheck.sh
# 輸出應顯示：HTTP/1.1 200 OK，包含院所代碼與健康狀態
```

### 步驟 5：本機 LLM 與離線語音辨識（Phase 33）
* **本機 LLM（`llama serve`，預設 `Gemma 4 E4B Q4_K_M`，對接 `8080` 埠）**：
  ```bash
  llama serve -hf unsloth/gemma-4-E4B-it-GGUF:Q4_K_M --port 8080 --ctx-size 32768 -ngl 99
  ```
  顯存充裕（≥12 GB VRAM）機房可改用 `Q8_0`（搭配 `config/llama_config.q8.example.json`、`--ctx-size 16384`）。
* **本機語音辨識（ASR）**：一律採用 `faster-whisper large-v3-turbo`（`uv sync --extra asr`，搭配 `config/asr_hotwords.json` 專科熱詞表與 Silero VAD），**勿以 Gemma 4 E4B 原生音訊直接進行門診長錄音轉錄**。
* **診間錄音上傳上限**：`POST /api/soap/recordings` 支援 `.wav` 與 `.opus`（上限 25 MB，建議診間優先傳送 Opus 壓縮音檔）。

## 三、診間端安裝流程（Windows 10 / 11 64-bit）

### 步驟 1：安裝檔完整性比對（安全要求 T-32-23-01）
為防止安裝包在傳輸過程中遭惡意竄改，請在安裝前使用 PowerShell 核對雜湊值：
```powershell
Get-FileHash .\ElcAgentSetup.exe -Algorithm SHA256
```
確認輸出雜湊值與官方交付清單一致。

### 步驟 2：執行安裝檔與 SmartScreen 警告處置（D-32-10）
1. 雙擊執行 `ElcAgentSetup.exe`。
2. **處理 Windows SmartScreen 藍色警告視窗**：
   * **背景原因**：本系統專供診所封閉內部網路專用，未向公網憑證機構購買每年高額之商業軟體簽名憑證。Windows 系統遇到未簽名的新安裝包會預設彈出「**Windows 已保護您的電腦**」藍色提示畫面。
   * **處置步驟**：
     1. 點擊畫面上的「**其他資訊 (More info)**」文字連結。
     2. 此時下方會出現「**仍要執行 (Run anyway)**」按鈕，點擊它即可順利進入安裝程式。
3. 依畫面指示點擊「下一步」，安裝程式會自動完成檔案複製並在桌面建立捷徑。

### 步驟 3：首次啟動三步精靈（B6 免打字設定）
安裝完成後首次啟動程式，系統會自動彈出 520×380 大字向導視窗：
1. **步驟 1（確認診所）**：程式自動透過 UDP 找到主機並顯示診所名稱（例如「安平診所」），請醫師或現場人員直接點選「**是**」。
2. **步驟 2（選擇診間）**：從下拉選單選擇這台電腦所在的診間（例如「第 1 診間」），點選「**下一步**」。
3. **步驟 3（選擇門診系統）**：下拉選單選取目前使用的門診 HIS 廠牌（如「展望」或「耀聖」），點選「**完成**」。
4. 點擊完成後，螢幕右下角即會出現紅綠黃燈快捷列，設定自動儲存至本機，日後開機即自動啟動。

## 四、常見疑難排解 (FAQ)

### Q1：首次啟動精靈顯示「找不到伺服器」？
* **檢查 1（實體線路）**：確認主機與診間電腦接在同一個分享器或交換器上，IP 網段相同（如皆為 `192.168.1.X`）。
* **檢查 2（主機服務）**：在診間電腦打開瀏覽器，輸入 `http://主機IP:5000/api/health`。若打不開，請檢查主機防火牆是否放行 5000 埠：
  ```bash
  sudo ufw allow 5000/tcp
  sudo ufw allow 5002/udp
  ```
* **手動退路**：點擊精靈畫面下方的「**手動輸入位址**」，鍵入主機 IP（例如 `192.168.1.50:5000`）即可強制連線。

### Q2：更換診所分享器後連不上主機？
* 本系統具備 **C3 斷線自癒機制**：若主機 DHCP IP 變更，診間 Agent 在偵測到連線中斷後，會在背景每 15 秒重新發送 UDP 廣播，自動比對 `facility_code` 院所代碼，一旦找到主機新位址即無縫重新繫結，完全不需工程師到場重設。

### Q3：想隱藏或重新開啟右下角快捷列？
* 請看 Windows 工作列右下角小箭頭（系統匣），在醫療十字圖示上按滑鼠右鍵，即可點選「**顯示/隱藏快捷列**」、「**重新校正 HIS**」或「**結束**」。
