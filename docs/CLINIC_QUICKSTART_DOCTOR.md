# 智慧門診病歷助理 — 醫師日常操作一頁指南

歡迎使用智慧門診病歷助理！本系統會在您問診時安靜聆聽並自動整理結構化病歷（SOAP），看診完畢後一鍵回寫至您的門診系統。

---

## 🚦 右下角快捷列：看懂「三顆燈」

螢幕右下角會常駐一個長條形小視窗，透過**三顆燈**與簡單按鈕引導看診流程：

| 狀態燈號 | 狀態意義 | 醫師操作說明 |
| :---: | :--- | :--- |
| 🟢 **綠燈** | **系統就緒，等待看診** | 病患就座後，點擊「▶ **開始**」按鈕，系統即開始為本位病患記錄問診。 |
| 🔴 **紅燈** | **正在即時錄音記錄** | 問診與檢查中請正常交談。診療結束時，點擊「■ **結束**」按鈕。 |
| 🟡 **黃燈** | **AI 產生病歷草稿中** | 系統正自動轉換病歷（約需 3–5 秒）。完成後會跳出確認視窗，確認無誤點擊「✔ **存檔**」，內容將自動寫回您的門診系統。 |

> 💡 **超簡單日常三步口訣**：
> **病患坐下按「開始」** ➔ **看診完畢按「結束」** ➔ **看過內容按「存檔」**！

## 🛠️ 常見狀況三招自救（免找工程師）

### 第 1 招：螢幕右下角找不到快捷列？
* **原因**：可能不小心最小化或被其他軟體遮住了。
* **解法**：請看螢幕最右下角的 Windows 工作列小箭頭（系統匣），找到綠色或藍色的「醫療十字」小圖示，點一下滑鼠左鍵，快捷列就會重新出現在最上層。

### 第 2 招：顯示「連線中斷」或「尋找伺服器」？
* **原因**：診所網路短暫波動，或網路線輕微鬆脫。
* **解法**：請檢查電腦後方的網路線或 Wi-Fi 連線。本系統具備**自動恢復機制**，只要網路通暢，15 秒內會自動重新連線回到 🟢 綠燈，您完全不需要重新開機或重新設定。

### 第 3 招：AI 產生的病歷想修改怎麼辦？
* **原因**：可能有特殊補充事項需要醫師親自註記。
* **解法**：在跳出的草稿確認視窗中，每個欄位（主訴、客觀檢查、評估、治療）都可以直接用滑鼠點選鍵入修改，修改完成後再按「✔ 存檔」，系統會以您修改後的最新版本為準。
